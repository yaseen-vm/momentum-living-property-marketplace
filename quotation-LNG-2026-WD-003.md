## Project Overview

A listing marketplace for properties, plots and rooms. Owners register as a vendor type (landlord, company, agent or broker) and are verified by the admin before they can post, and every listing is approved before it appears publicly. Vendors and customers both verify their mobile by SMS OTP. Customers search approved listings and register interest; the admin is notified and closes the deal offline.

## How the Platform Works

| Stage | What Happens |
|-------|-------------|
| 1. Vendor signs up | Registers as landlord, company, agent or broker, verifies mobile by SMS OTP and uploads the required documents. |
| 2. Admin verifies vendor | Admin reviews the documents and approves or rejects. Only verified vendors can post. |
| 3. Vendor submits listing | Property, plot or room listing created with photos and details, submitted for review. |
| 4. Admin approves listing | Admin checks the listing and publishes it, requests changes, or rejects it. |
| 5. Customer verifies & searches | Customer signs up, confirms their mobile by SMS OTP, then searches approved listings. |
| 6. Interest raised, admin closes | Customer registers interest and the admin is notified with both parties' contacts. Admin confirms availability with the owner, calls the customer and collects payment offline. |
